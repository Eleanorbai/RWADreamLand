# RWA Dream Land 四个核心区域功能设计规格

## 设计理念

基于rwa.xyz平台的专业数据展示和分析功能，结合现有RWA Dream Land的学习共创理念，设计四个功能互补、数据流通的核心区域。

## 1. 灵感广场（资讯/观点/研究区）

### 功能定位
内容聚合和知识共享的核心区域，类似rwa.xyz的新闻和研究博客功能，但更加注重用户生成内容和互动。

### 核心功能

#### 1.1 内容流展示
- **多维度筛选**：按内容类型（案例研究/学习笔记/商业模型）、标签、时间、热度排序
- **智能推荐**：基于用户兴趣和行为数据的个性化内容推荐
- **内容卡片**：展示标题、摘要、作者、发布时间、互动数据（浏览/点赞/评论数）
- **标签系统**：支持多级标签分类，颜色编码，热门标签云展示

#### 1.2 内容创作和发布
- **从笔记发布**：用户可将个人笔记一键发布到广场
- **直接创作**：支持在广场直接创建内容，使用Markdown编辑器
- **内容审核**：内容发布前可选择提交审核，通过后获得积分奖励
- **渐进式披露**：支持内容摘要公开，详细内容需要一定积分或权限查看

#### 1.3 互动功能
- **点赞收藏**：一键点赞，支持收藏夹分类管理
- **评论讨论**：支持富文本评论，楼中楼回复
- **分享转发**：内容分享到小组或其他平台
- **专家评价**：认证专家可对内容进行专业评价和推荐

#### 1.4 数据分析展示
- **热度指标**：实时展示内容热度排行、趋势分析
- **知识图谱**：展示内容间的关联关系，主题聚类
- **贡献排行**：作者贡献度排名，积分统计

### UI设计要点
- 保持现有的蓝色主题色调，增加绿色和橙色作为强调色
- 卡片式布局，支持列表和网格两种视图模式
- 响应式设计，移动端优化
- 无限滚动加载，流畅的用户体验

## 2. 情报港（数据/分析/工具区）

### 功能定位
参考rwa.xyz的数据分析和工具功能，提供专业的RWA市场数据、分析工具和资源库。

### 核心功能

#### 2.1 数据看板
- **实时指标**：模拟rwa.xyz的关键数据展示（总价值、资产类别、交易量等）
- **趋势图表**：时间序列图表，支持多维度对比分析
- **市场热力图**：直观展示不同RWA领域的活跃度
- **数据筛选**：按时间段、资产类型、地区等维度筛选

#### 2.2 分析工具
- **项目评估**：RWA项目评估模板和工具
- **风险计算器**：投资风险评估和收益计算工具
- **对比分析**：多个项目或资产的横向对比
- **模型模拟**：商业模型可行性分析工具

#### 2.3 资源库
- **研究报告**：行业报告、白皮书、分析文档
- **法规政策**：相关法律法规和政策解读
- **案例库**：成功/失败案例深度分析
- **工具模板**：项目计划书、尽调清单、合规模板

#### 2.4 问答社区
- **专业问答**：技术、法律、商业等专业问题讨论
- **专家解答**：认证专家提供权威解答
- **悬赏问题**：积分悬赏征集解答
- **知识库**：常见问题和最佳实践整理

### UI设计要点
- 紫色主题色，体现专业和权威感
- 数据可视化重点突出，使用图表库
- 工具界面简洁实用，表单优化
- 支持数据导出和API接口

## 3. 原点馆（RWA项目馆）

### 功能定位
项目孵化和团队协作中心，支持RWA项目的全生命周期管理和团队协作。

### 核心功能

#### 3.1 项目展示
- **项目画廊**：项目展示卡片，包含项目简介、进度、团队信息
- **项目分类**：按行业、阶段、规模等维度分类展示
- **项目详情页**：完整的项目介绍、商业计划、团队成员、进展更新
- **项目评级**：社区评级和专家评分系统

#### 3.2 团队协作
- **小组创建**：项目发起人可创建协作小组
- **成员招募**：发布招募信息，设置技能要求和角色分工
- **权限管理**：小组内分层权限，项目资料访问控制
- **协作空间**：小组内的文档共享、任务管理、沟通工具

#### 3.3 项目管理
- **里程碑跟踪**：项目进度可视化展示
- **任务分配**：团队任务分工和进度跟踪
- **文档管理**：项目文档版本控制和共享
- **会议记录**：会议安排和纪要管理

#### 3.4 孵化支持
- **导师匹配**：项目与行业导师的匹配推荐
- **资源对接**：投资人、合作伙伴、服务商对接
- **培训课程**：项目管理、商业模式等专业培训
- **路演展示**：项目路演活动和投资人见面会

### UI设计要点
- 橙色主题色，传达创新和活力
- 项目卡片设计突出视觉效果
- 协作界面注重实用性和效率
- 支持文件上传和在线编辑

## 4. Dock讨论区（社区/互动区）

### 功能定位
开放式社区讨论平台，促进用户间的深度交流和知识分享。

### 核心功能

#### 4.1 话题讨论
- **话题分类**：技术讨论、市场分析、法规政策、项目分享等
- **热门话题**：基于参与度和互动数据的热门话题推荐
- **话题标签**：多维度标签体系，便于检索和分类
- **话题置顶**：管理员可置顶重要讨论

#### 4.2 社区互动
- **实时聊天**：支持即时通讯功能
- **语音讨论**：语音聊天室，在线语音讨论
- **活动组织**：线上/线下活动组织和报名
- **投票调研**：社区投票和问卷调研功能

#### 4.3 用户系统
- **用户认证**：实名认证、专家认证、机构认证
- **声誉系统**：基于贡献度的用户等级和声誉值
- **关注订阅**：用户互相关注，订阅感兴趣的话题
- **私信系统**：用户间私密沟通

#### 4.4 内容治理
- **社区规则**：明确的社区行为准则和违规处理机制
- **内容审核**：AI+人工的内容审核机制
- **举报处理**：用户举报和管理员处理流程
- **信用管理**：用户信用评分和限制机制

### UI设计要点
- 青色主题色，营造轻松友好的氛围
- 聊天界面参考主流社交软件设计
- 讨论串展示清晰，支持富文本和多媒体
- 移动端体验优化，支持推送通知

## 跨区域功能整合

### 数据流通
- **内容流转**：笔记→广场→项目→讨论的完整内容生命周期
- **用户画像**：跨区域用户行为分析和个性化推荐
- **积分系统**：统一的积分获取和消费机制
- **搜索引擎**：全平台内容的统一搜索和推荐

### 权限管理
- **角色体系**：普通用户、认证专家、项目负责人、社区管理员、平台管理员
- **内容权限**：基于积分、角色、小组成员身份的内容访问控制
- **功能权限**：不同角色在各区域的功能权限差异化

### 通知系统
- **站内消息**：系统通知、互动提醒、审核结果等
- **邮件通知**：重要事件的邮件提醒
- **推送通知**：移动端推送通知
- **订阅管理**：用户自定义通知偏好设置

## 技术实现要点

### 后端扩展
- 基于现有SQLModel模型扩展新的数据表
- 利用现有的FastAPI路由架构添加新接口
- 保持现有的JWT认证和权限控制机制
- 集成现有的区块链积分系统

### 前端开发
- 复用现有的React组件和shadcn/ui组件库
- 保持TailwindCSS样式系统的一致性
- 利用现有的API调用模式和错误处理机制
- 实现响应式设计和移动端适配

### 性能优化
- 数据分页和虚拟滚动
- 图片懒加载和CDN优化
- API缓存和状态管理优化
- 数据库查询优化和索引设计

### 扩展性设计
- 插件化架构支持功能扩展
- API设计支持第三方集成
- 数据模型设计支持未来功能扩展
- 配置化管理支持个性化定制
